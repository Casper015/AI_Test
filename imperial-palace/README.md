# 紫禁天朝 · 皇家宫城 3D 导览

一个基于参考布局图进行艺术化演绎的交互式皇家宫城沙盘。首屏展示完整城墙、护城河、桥梁、中轴前朝、东西侧院、后宫和御花园；可选择建筑查看档案、跳转分区、沿中轴巡游、进入代表性殿堂、切换昼夕夜并开启第一人称漫游。

## 运行

需要 Node.js 20.19+ 或 22.12+，以及 npm。项目使用 Vite 开发服务器和 Three.js；只使用 npm，并提交锁文件。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。生产构建和本地预览：

```sh
npm run build
npm run preview
```

构建输出为 `dist/`，可由任意静态 HTTP 服务托管。运行时不依赖外链模型、纹理或字体。

## 操作

- 拖动场景旋转，滚轮缩放；点击建筑可查看档案与可进入状态。
- 左侧按钮跳转全城、前朝、主殿、后宫、东西宫苑和御花园。
- 太和殿与乾清宫可从建筑档案进入室内展示；进入时暂时隐去对应屋顶，再按“退出殿内”返回。
- “沿中轴巡游”自动依次访问前朝、太和殿、后宫与御花园；手动操作会中止巡游。
- 点击“第一人称漫游”或按 `F` 进入漫游；`WASD`/方向键移动、`Shift` 加速、`Esc` 释放鼠标。
- 时辰预设包括金辉、落霞与寒月；小地图标出城界、中轴、建筑与相机目标。
- 右上角按钮切换全屏；“回到全城”复位镜头。

## 项目组织

- `imperial-palace-plan.md`：完整需求与阶段验收计划。
- `assets/reference/`：用户提供的布局参考图。
- `src/shared/config.js`：视觉 token、时辰、分区相机与边界配置。
- `src/zones/catalog.js`：建筑注册表、院落与连接点。
- `src/kit/architecture.js`：共享建筑、屋顶、柱网、院墙与景观构件。
- `src/zones/createPalace.js`：场景、宫城边界、水系与全城装配。
- `src/main.js`：交互、相机、光照、拾取、漫游与唯一渲染循环。
- `docs/`：风格、接口与资产记录。

当前布局清单登记 **60 座独立建筑、16 个围合院落、5 个跨区连接点**。建筑均为程序化几何；数量和名称属于本项目演绎设定，不是史实考据。两个室内采用可视化展陈，不是完整可通行房屋建模；漫游碰撞采用建筑 footprint 近似，院墙/栏杆的逐段物理碰撞仍可继续完善。

## 检查

```sh
npm run check:layout
npm run build
```

`check:layout` 检查 ID 唯一性、建筑/院落数量下限、区域分布与连接点；浏览器内仍应检查实际视觉、交互和设备性能。整城采用 InstancedMesh 批次控制 draw calls，但完整 GPU、帧率、P95 帧耗时与低端设备测试尚未采样。
