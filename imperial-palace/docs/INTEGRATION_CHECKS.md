# 整城集成检查

检查日期：2026-09-26。项目根目录：独立 `imperial-palace/` 文件夹。

## 通过项

- `npm run check`：通过；注册表有 88 栋建筑、20 座庭院和 11 个唯一连接点，并检查了每个网格的顶点坐标均为有限数。
- `npm run build`：通过；Vite 生成可由 HTTP 服务运行的 `dist/`。
- 本地浏览器检查（1280×720）：加载完成后可见整城鸟瞰；宫墙闭合，南北轴线、左右宫苑和北部花园均在同一场景中。总览镜头略微拉近，东西苑和花园使用斜俯机位。
- 分区导航、回到总览、昼景/夕照/夜景切换以及中轴导览的启动和停止均有响应。
- 太和殿与紫宸寝殿可被选中；信息卡分别显示“可进入 · 内景开放”。漫游按钮能切换到第一人称视角，按钮再次点击能回到轨道视角。
- 主要面板统一为 6px 圆角、按钮为 4px 圆角；区域共用同一套建筑 kit 和色彩 token。

## 尚未验证或未达标

- **性能目标未通过验收**：浏览器全景记录到约 3,637 次主场景绘制调用、76k 三角面。计划中的 ≤350 draw call 目标尚未达到；没有采集 30 秒 FPS、P95 帧耗时或实际设备信息。构建成功但主 JS chunk 为 778.32 kB（gzip 199.74 kB），Vite 对超过 500 kB 的 chunk 发出提示。
- **漫游路线待实走**：已确认第一人称模式可开启和退出，但尚未沿南门到主殿、寝殿的完整路线逐段验证门洞、台阶、桥面和墙体碰撞。
- 太和殿有可见门洞与简化宝座/屏风；紫宸寝殿有床榻和屏风构件。两处可进入状态已在选择面板确认，室内细节和实际穿门路径仍需近景验收。
- 暂未接入第三方模型或贴图；项目允许后续接入，当前场景由共享程序化构件生成，因此无需第三方资产署名。
- 内廷门殿的无效高度参数已修正；实景热重载后没有再出现 NaN 几何警告。Three.js `Timer` 与 `PCFShadowMap` 已替代本机预览曾提示弃用的旧 API。
- 浏览器核对属于本地视觉与基本交互检查，没有保存截图，也未在其他浏览器或移动设备上验证。
