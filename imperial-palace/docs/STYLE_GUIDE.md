# 风格基线 v1.0.0

## 方向

参考随计划归档的宫城鸟瞰图，采用略带风格化的皇家沙盘表现。以连续南北礼仪轴线、金黄屋顶、朱红木作、灰白台基、围合院落与北部御花园为视觉识别点。项目是基于布局关系的艺术化演绎，不声称精确复原历史建筑原址或尺寸。

## 共享色彩与尺度

- 琉璃瓦金：`#dfa112`；高光瓦：`#efbd4c`；鎏金：`#ffc83b`
- 宫红：`#962822`；深朱：`#681f1b`；青绿梁枋：`#1c4e40`
- 白石：`#f0ece1`；铺地：`#77756f`；庭院松绿：`#3d5942`
- 统一世界单位为米，Y 向上、X 向东、Z 向北；建筑正面朝南。
- 主殿通过开间、台基与重檐层级强调主次；配殿、院门、亭阁沿用同一屋顶与柱网语汇。
- 光照由主场景统一控制，昼、夕、夜共用材质与场景；宫灯以自发光材质表现。
- HUD 使用系统衬线中文字体，暗色半透明面板、暗金细线与朱色/金色强调，不加载远程字体。

## 验收视角

固定检查全城鸟瞰、前朝、太和殿近景、后宫、东西侧院和御花园。确认屋顶主次、院墙边界、南北中轴、护城河与桥梁在各时辰均可辨识。
