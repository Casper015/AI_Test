# 整城集成与验收记录

日期：2026-09-26。最终目录：`imperial-palace/sol/`。原同名目录在开发中被另一进程并行写入，所以本次工程隔离到 `sol/`，未覆盖兄弟文件。

## 已验证

- `npm ci` 成功；`npm run check` 通过：88 栋稳定 ID 建筑、20 座注册院落、11 个唯一连接点，所有区域网格坐标均为有限数。
- 静态合批检查：1372 个静态 Mesh 变为 116 个场景 Mesh（其中 20 个材质批次）；88 栋建筑在合批后均保留面级拾取映射。真实浏览器点击仍能选中建筑，主殿出现入内按钮。
- `npm run build` 成功；`dist/index.html` 引用 `./assets/...` 相对资源路径。最终主 JS 约 788 kB、gzip 203 kB，Vite 有大于 500 kB 的包体提示，但不是构建失败。
- Playwright 浏览器 `1440×900` 与应用内浏览器的桌面/窄屏观察：首屏可见完整城墙、中轴、东西院与北苑；宫殿点选、分区跳转、昼夕夜切换、太和殿内景机位均有响应。手机窄屏改为横向分区导航，点选建筑有效。
- 开发预览鸟瞰在稳定采样时约 112 次绘制/帧、10 万可见三角；近景或漫游启用单盏近场阴影时约 150 次绘制/帧、19 万含阴影三角。数字来自 `renderer.info.render`，含阴影成本，不冒充单独主场景值。Playwright 约 30 秒滚动窗口曾读到约 60 FPS、P95 17 ms；热更新/构建并行时读到 55 FPS、P95 33 ms，因此不作为所有设备的性能承诺。浏览器 GPU 型号未记录。
- 南桥头开始漫游后，浏览器状态显示 `mode: walk`、起点 `(0,1.75,-480)`；主区静态路径/碰撞抽查见各分区交付回执。外墙 8 段碰撞、四桥窄带与陡阶阈值由统一控制器处理。
- 最终把漫游高度/碰撞抽成同一可测模块，`npm run check` 的步行检查覆盖南桥 180 个半米采样、护城河/实墙/门洞，并以 2 米网格从南桥搜索到前朝、太和殿入口与内景、内廷寝殿内景、御花园六个目标。该检查发现太和殿楼梯到台基间高度断层，现已补上中央/侧翼石平台并修正高度模型；最终结构测试通过。它不替代真实键鼠实走。
- 原压缩包的计划和参考图 SHA-256 与 `original-archive-SHA256.json` 一致；场景没有第三方模型/贴图/字体或运行时热链。
