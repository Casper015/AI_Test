# 视觉基线 v1

所有区域 Agent 开工前必读。固定 `1440×900`、DPR 1 的首轮整城样板见 [overview-v1-baseline.png](style-reference/overview-v1-baseline.png)；这张图记录场景结构和初始配色，最终 UI/细节变化以最新项目预览为准。

## 视觉目标

一座略带风格化、尺度完整、可自由游览的皇家宫城。整体形制庄严对称、建筑群层层推进；远景靠屋顶与红墙形成统一轮廓，近景显出白石、木作、斗栱与檐脊层次。亮金屋顶是主视觉，花园、水面和树冠负责调节密度。

统一世界单位为米，Y 向上，北为 `+Z`，南为 `-Z`。主材质通过 `kit.materials` 获取，区域不定义私有的红、金、石或水色。屋顶统一低金属、柔和清漆感，鎏金小件可提高金属度；色调映射只在 renderer 设置一次。

## 建筑模数与构成

共享构件库定义檐口、屋脊、开间、墙体、柱、门窗、台基、踏步与栏杆。主殿比例和装饰等级最高；次殿、配殿、门楼、廊房依次降低，不能通过换颜色造成假层级。同类屋顶共用坡度、翘角和脊兽尺度。

院落地面为沉稳灰石，主轴可使用宽石板/砖石路。宫墙保持朱红与较低高度，边界城墙比院墙厚且带连续城垛。树木统一低饱和枝冠簇，不混入写实照片树。水体反射克制，不盖过屋顶。

## 镜头和 UI

- 默认全城机位由配置 `views.overview` 唯一管理；区域机位数据来自共享布局。
- UI 使用宋体/衬线中文标题、朱印、暖金细边、深绿黑半透明底。间距 `4/8/12/16/24/32px`，面板圆角 6px。
- 旋转、导览、选中和漫游都驱动同一相机/状态管理；区域代码不直接操作全局相机。
- 固定样板检查窗口 `1440×900`，统一 DPR 1、默认 noon 光照与 overview 视角；共享布局机位为 `[620,720,-850]` 看向 `[0,0,10]`。

## Agent 验收

新模型先在样板机位中检查：屋顶金色是否接近、柱墙是否偏橙/偏紫、石材粗糙度是否一致、整体尺寸是否符合米制、近远景细节级别是否合适。差异显著时先适配材质和缩放，再提交区域；不得把来源模型原材质直接带入整城。
