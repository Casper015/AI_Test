# 紫禁天朝 · 完整皇宫 3D 交互（GPT-6 Sol）

参照随项目保存的宫城布局图，制作的可俯瞰、选殿、沿中轴导览和第一人称漫游的皇家宫城沙盘。此为艺术化设计，不宣称按史实精确复原。本项目由 ChatGPT（GPT-6 Sol 会话）自主完成，最终工程放在 `imperial-palace/sol/`，其代码、资源和依赖自成一体；无需运行时联网素材。

## 运行

需要 Node.js 20.19+。在本目录执行：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

浏览器打开终端显示的本地地址。生产构建与结构检查：

```sh
npm run check
npm run build
npm run preview -- --host 127.0.0.1
```

`dist/` 为可由 HTTP 服务预览的构建产物，资源使用相对路径。不要直接用 `file://` 打开入口：浏览器模块加载与指针锁需要本地 HTTP 页面。

## 游览

- 鼠标拖动环视、滚轮缩放、右键平移；触屏单指环视、双指缩放。点击建筑查看名称与可进入状态。
- 小地图选择南门、前朝、主殿、后宫、东西宫苑或御花园；“回到全城”复位镜头。选中可进入建筑后，可用“入内观赏”切换到内景机位。
- 中轴导览可暂停和继续；手动操作镜头或切换分区会结束导览。
- `F` 或漫步按钮从南桥头进入第一人称；`WASD`/方向键移动，`Shift` 加速，鼠标转向。`Esc` 暂停指针锁，再按 `F` 或点击恢复。桌面键鼠是漫游模式的预期操作方式。
- 盛世金辉、落霞夕照、寒月宫灯切换全城光照；画质按钮切换高清/流畅。

## 内容与实现

场景由五个分区与共享建筑构件库组成：中轴前朝、后宫、西苑、东苑，以及花园/城墙/护城河。稳定注册表包含 88 栋建筑与 20 座围合院落；主殿和一处寝殿设内景，其余建筑优先提供外观。Three.js + Vite 负责渲染与构建；代码、参考图、依赖锁文件和构建结果均在此项目内。
