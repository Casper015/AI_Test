# 紫禁天朝 · 东方皇家宫殿 3D 视觉基线规范 (Style Guide v1.0)

本项目基于明清官式皇家建筑语言，追求**精致、宏阔、略带风格化的皇家宫城沙盘**美学，突出金顶、朱墙、白石、青绿彩画与深幽院落的秩序感与历史厚重感。整座宫城在远景靠黄色琉璃瓦与红墙形成统一轮廓，近景展现汉白玉雕花台基、斗栱出檐、金砖地面与内景陈设。

## 二、 建筑形制与构件模数规范

1. **屋顶等级序列**：
   - **最高等级**：太和殿（金銮殿）采用**重檐庑殿顶**（Double-Eave Wudian），正脊平直，四面大坡，出檐深远；
   - **第二等级**：保和殿、太和门、乾清门、皇极殿采用**重檐歇山顶**（Double-Eave Xieshan），带三角形悬鱼山花；
   - **方正礼仪**：中和殿、交泰殿采用**单檐四角攒尖顶**（Pyramidal），顶置鎏金宝顶；
   - **御苑名胜**：万春亭、千秋亭采用**重檐八角圆攒尖顶**（Circular / Octagonal Double-Eave），金宝顶耸立；
   - **四角角楼**：紫禁城四角角楼采用独一无二的**九梁十八柱七十二条脊复合十字歇山顶**；
   - **藏书圣地**：文渊阁采用**黑琉璃瓦绿剪边歇山顶**。
2. **台基与基底**：
   - 太和殿、中和殿、保和殿屹立于三层连体汉白玉须弥座台基（高 4.5m）之上，四周环绕雕花望柱与栏板，正面设云龙丹陛御道；
   - 其他殿宇台基按规制设置 1.1m - 2.2m 汉白玉台明与踏步台阶。
3. **空间尺度基准**：
   - 统一世界单位为米（m），以 Y 向上为高程，以北向 +Z 为深进，以南向 -Z 为迎朝，以东向 +X、西向 -X 分布左右六宫与宫苑。
   - 宫城矩形包络：`X ∈ [-300, 300]`，`Z ∈ [-450, 450]`（600m × 900m），外绕 38m 宽筒子河护城河。

## 三、 三时辰光照与环境氛围

1. **盛世金辉（正午 Golden Noon）**：
   - 主太阳光自南偏西 45° 照耀，照度 3.2，暖米白色光线使琉璃金顶金光万道；
   - 天空呈现淡淡的金白暖霞，环境反射柔和庄严。
2. **落霞残阳（傍晚 Sunset Dusk）**：
   - 太阳沉落于西地平线 15°，强烈的深橙赤红光束斜射宫墙，投下深邃修长的侧影；
   - 天空泛起紫红色暮霭，宫殿金瓦反射熔金暮色。
3. **寒月孤灯（夜景 Cold Moonlight）**：
   - 冷清幽蓝的明月自中天倾泻，冷调天幕与深蓝薄雾笼罩紫禁城；
   - 乾清门、养心殿、内廷连廊与各庭院宫灯点亮暖橙色烛光，映照红墙深殿。

## 四、 界面与交互规范

- **UI 风格**：以深色半透明毛玻璃 (`rgba(18, 24, 34, 0.78)`) 为底，配合 `1px solid rgba(212, 175, 55, 0.32)` 细金线条与朱砂印章标识；
- **排版字体**：标题选用 `Cinzel` 与 `Noto Serif SC` 典雅宋体，彰显皇家威仪；
- **响应式布局**：全端支持，手机与平板自适应收纳工具栏，保障触控体验流畅。
