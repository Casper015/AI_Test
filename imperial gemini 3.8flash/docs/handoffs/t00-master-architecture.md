# 任务回执 T00 · 主 Agent 架构设计与工程脚手架统领

- **执行 Agent**：主 Agent (Master Architect / Gemini 3.8 Flash)
- **基线版本**：Style Guide v1.0 / Contracts v1.0
- **工作目标**：确立工程目录架构、全城坐标体系包络、模块划分、单一 RAF 渲染管线、全局光照与三时辰预设、自动化校验与持续集成基线。

---

## 交付产物与核心决策

1. **工程架构与无外部包网络依赖**：
   - 确立 Vite + Three.js 现代化构建体系；
   - 依赖仅限于 `three` 与 `vite`，全场景构建几何无任何第三方大模型资产网络阻塞风险；
   - 设置 `base: './'` 确保任何本地静态 HTTP 服务与 GitHub Pages 部署路径兼容。
2. **全城空间坐标体系与区域划分**：
   - 设定世界坐标中心为 `(0, 0, 0)`，以米为单位；
   - 宫城包络 `X ∈ [-300, 300]`，`Z ∈ [-450, 450]`；
   - 划分 5 大施工责任区（前朝、后宫、西宫苑、东宫苑、御花园与边界），明确各区域边界与连接契约。
3. **单一动画循环管线 (Single RAF Pipeline)**：
   - 严禁各子 Agent 私自启动 `requestAnimationFrame`；
   - 统一由 `src/main.js` 统一帧调度，按序执行输入更新、控制器平滑插值、场景渲染与雷达雷达绘制。
4. **自动化检验工具**：
   - 编制 `scripts/check.mjs`，包含静态语法解析、网格顶点有限值校验（零 NaN / 零 Infinity）、建筑与庭院规模断言、跨区连接点所有权唯一性校验。
