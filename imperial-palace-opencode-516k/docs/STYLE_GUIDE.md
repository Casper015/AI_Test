# STYLE GUIDE · 紫禁天朝

- 基线版本：`v0.9`（主 Agent 初始发布，A 细化后升 `v1.0`）
- 适用范围：全城所有区域、构件、材质、UI、动效与视角
- 冲突处理：本文件与 `src/shared/config.js` 冲突时以 `config.js` 为准，由主 Agent 同步修正后升版本

## 1. 定位

精致、略带风格化的皇家宫城沙盘：明清官式建筑语言，金顶、朱墙、白石、整齐院落；远景轮廓清晰，近景细节克制；材质光泽收敛；全城同一套模型语言。

## 2. 单位、朝向与坐标

- 单位米，Y 向上，X 向东，Z 向北；地面 `y = 0`；建筑正面朝南（`-Z`）。
- 宫墙包络 `X ∈ [-300,300]`、`Z ∈ [-450,450]`；护城河在墙外 `|x| ∈ (300,345]`、`|z| ∈ (450,495]`。
- 台基、桥面、室内地面等标高由 `layout.js` 与各区域登记，禁止私自抬高全城地坪。

## 4. 建筑形制

- 主殿：重檐庑殿顶，九开间，三层白石台基，栏杆、丹陛、御道齐全。
- 次级殿堂：单檐庑殿或歇山，五至七开间，单层台基。
- 宫门：三至五开间，红色板门 + 鎏金门钉，金瓦屋顶；城门为城台 + 城楼。
- 亭：方形攒尖顶，宝顶鎏金，四柱开敞。
- 角楼：三层重檐，方形，金顶。
- 廊庑：连续红柱 + 小坡瓦顶，檐高低于配殿。
- 屋顶参数（由 `config.js` 的 `ROOF` 提供）：檐口外挑约为开间模数的 1.18 倍，起翘角高 `0.55m`，凹曲指数 `1.25`，正脊高 `0.7m`。

## 5. 材质规范

- 琉璃瓦：`roughness 0.42`、`metalness 0.12`，不做镜面反射；瓦垄用横向条纹贴图或几何线脚表现。
- 鎏金：唯一明显金属（`metalness 0.7`、`roughness 0.28`）。
- 白石：`roughness 0.75`，微暖，荒料感弱。
- 木作：`roughness 0.85`，颜色按宫红，轻微纹理；无写实木纹照片贴图。
- 铺地与金砖：`roughness 0.9`，深色，不反光。
- 水面：`roughness 0.12`、`metalness 0.1`、轻微透明，低饱和。
- 旧化：统一且轻，禁止局部重污损。

## 6. 植物、摆件与小品

- 乔木统一两档：松（三层锥形冠）、阔叶（球冠）；高度 6–12m，树冠饱和度一致。
- 假山用低面数多面体，灰白；石栏、铜器、石灯、香炉、旗幡按 kit 统一件，不各自造形。
- 远景区块可以用同一 kit 的低细节档（LOD1/LOD2）。

## 7. 光照与时辰

- 三预设：`golden 盛世金辉`、`dusk 落霞夕照`、`night 寒月宫灯`。太阳方向、天空、雾、曝光、环境光比例由 `core/environment.js` 统一。
- 阴影：一盏主方向光，阴影相机随观察目标移动（半径约 150m）；宫灯不投影。
- 夜景：按距离激活有限点光（≤ 24 盏），远处用自发光材质替代；金瓦在夜景中仍可辨纹。

## 8. UI 与动效

- 中文衬线标题、朱红印章、暗金细线、深色半透明面板；间距阶梯 `4/8/12/16/24/32px`；圆角 `4px`。
- 相机过渡统一 `1.2s`，UI 过渡 `180ms`；烟、树、水缓慢；全场一个动画循环。
- 视角切换器（多角度模式）与时辰、质量为同一套控件样式。

## 9. 验收视角（截图索引 `docs/shots/`）

固定 `1440×900`、DPR `1`，每个视角截图命名 `view-<mode>-<preset>.png`：

| 模式 | 参数来源 | 画面要求 |
| --- | --- | --- |
| `oblique` 全城鸟瞰 | `config.js` `VIEWS.oblique` | 宫墙闭合、中轴贯通、护城河完整 |
| `iso` 等距沙盘 | `VIEWS.iso` | 45°/35.26°，水平居中，无裁切 |
| `axis` 中轴透视 | `VIEWS.axis` | 南门至主殿序列可读，无遮挡爆框 |
| `zone` 分区 | 区域登记的 `zone` 机位 | 该区域主殿居中，配殿与围墙入画 |
| `focus` 近景 | 选中主殿 | 正前 3/4 视角，屋檐、斗栱、台基可辨 |
| `interior` 室内 | B/C 登记的 `interior` 机位 | 宝座/床榻居中，藻井可见，不穿墙 |
| `fp` 第一人称 | `fp-spawn` + 视线高度 | 站立于可行走面，水平线正常，无穿模 |
| `orbit` 自由环绕 | 默认环绕主殿 | 极角/距离限制生效，目标不失控 |

三个时辰各出一轮；风格检查项：屋顶同色同光泽、比例协调、铺地尺度一致、围墙连续、树木同风格、UI 同字体同间距。
