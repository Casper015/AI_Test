| 要素 | 实现（逐项核对） |
| --- | --- |

| **四向** | `for (const [dx2, dz2] of [[1,0],[-1,0],[0,1],[0,-1]])`（t159 修正，见 §2） |

## 2. 自查留痕：初版"门轴 = 几何长边"造成过**假绿**（必须留档）

### 2.1 事实（按原样登记，不美化）

- F3 断言**初版**把"**门轴**"**误取为几何长边**（`axisX = bw >= bd`），且**只比较该轴一个方向**；
- 在这一定义下，**真实突变**（C 两殿门外 `descent-*` = 1.9/1.4，真跳在 **x 向**）**报失败 0** ⇒ **假绿**（护栏看起来活着，其实没在判真正要判的那条跳）；
- 它在 **t159 的"复测突变"环节被发现**（突变下的命中清单为空，与预期不符 ⇒ 反查采样方向），随后**定点改为四向**（`[[1,0],[-1,0],[0,1],[0,-1]]`）；
- 改为四向后**立即报出** `WK-C-side-west-main-descent-1(-45,168)y1.90→(-44,168)y2.40 上行 0.5000 > 0.5` **+ 东侧镜像**。

### 2.2 当前树保留的痕迹（只读引用）

```text
const axisX = bw >= bd;                        // 门轴 = 较长的那个方向（本类带均为 x 向）
...
/* t159 修正：**四向**都取邻（门轴 x 向是关键：C/B 门的接近方向；z 向邻格为带内同高 ⇒ Δ=0 不误报） */
```

⇒ 长边启发式**仅用于选取中带 3 格的采样列**（`mid`），**判据侧已改为四向**，故"长边取错"不再能掩盖 x 向的真实跳变。
