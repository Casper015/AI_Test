## 4. C. 「每段边界墙恰由一个区域建造」与「5 个边界单层」独立复核（**唯一 FAIL**）

### 4.2 判定
- **`FAIL`（登记层「单层」）**：卡内期望「这 5 个边界当前应为**单层**；若仍是双层/4 段 ⇒ 标 FAIL 交回」。实测 **5/5 仍是 4 段（每侧 2 条同址记录）**；其中 **z=80 的同址对跨 B/C 两个区域**（B 的 `CY-B-rear-wall-north` 与 C 的 `CY-C-front-wall-south` bounds 完全相同）⇒ 若按边界线口径解读「恰由一个区域建造」，z=80 亦不成立。
- **碰撞层 `PASS`（同一时点）**：`deriveWallColliders(WALLS)` 对同址段做了**归并**：每侧恰 **1 个碰撞盒**，`wallIds` 把被并入的 id 全部列出（如 z=−180 两侧盒各含 4 个 wallId；z=80 两侧盒含 B+C 共 4 个 id）。**因此不存在"重复阻挡/空气墙"**：7 个口的通行性实测（§3）与 43/43、49/49（§2）都印证。
- **影响面（量化，供裁定参考）**：登记层冗余 ⇒ 1）**几何重复构建**：B 与 C（或同区两院）各按自己的 `WALLS` 记录建一次同址墙 ⇒ 同一道墙叠两层网格（合批后不增批次，但三角面与 z-fighting 风险按倍数存在）；2）**"每段恰一区"可核性下降**：z=80 一墙两主；3）**未观测到功能缺陷**（通行/可达/护栏均绿）。
