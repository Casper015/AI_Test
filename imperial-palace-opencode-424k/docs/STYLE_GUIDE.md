# 紫禁天朝 · 风格基线（STYLE_GUIDE）

- 基线版本：**style-baseline-v1**（与 `src/shared/config.js` 的 `VERSION` / `BASELINE` 同版）
- 布局版本：**layout-v1**（`src/shared/layout/`，主 Agent 冻结，区域模块只读）
- 单位与坐标系：米，Y 向上，X 向东，Z 向北；建筑正面朝南（-Z）；宫城地面中心 `(0,0,0)`
- 参考图：`assets/reference/palace-layout.png`（用户提供，用于布局与层级参考）

## 1. 风格定位

精致、略带风格化的明清皇家宫城沙盘：金瓦、朱墙、白石、灰砖铺地，中轴开阔、左右院落密集、北部园林，远景轮廓清晰、近景细节克制统一。全部构件由 `src/kit/` 程序化生成，不混用不同题材的外部模型；同一套构件语言贯穿全城。

## 3. 视角与镜头（唯一相机装置 `src/core/camera-rig.js`）

八种视角共享一部装置：`oblique`（全城鸟瞰，1）、`iso`（等距正交沙盘，2）、`axis`（中轴透视，3）、`zone`（分区，4）、`focus`（建筑近景 3/4，5）、`interior`（室内，6）、`fp`（第一人称，7）、`orbit`（自由环绕，8）。过渡统一 1.2 s（`UI.transitionMs`），UI 过渡 180 ms；分区/近景机位由 `layout-v1` 的 `viewpoints` 冻结登记，G 只读消费。

## 7. 风格验收结论（style-baseline-v1）

- 屋顶同色同光泽、同类建筑坡度一致；殿堂比例按等级递减；铺地密度全城一致（UV 以米为单位）。
- 院墙连续、跨区接口对齐（13 个连接器全部落在共享边界或宫城边界，见 `npm test`）。
- 树木、山石、宫灯、陈设同一套构件；UI 同一套字体（宋体标题 + 造字印章）与 4/8/12/16/24/32 间距。
- 昼景通过后检查夕照与夜景，三时辰均无过曝或不可读暗区。
